# Post-label preview

## Agreed decisions

Continue toward a Bluesky labeler that attaches labels to posts. The next local preview will show the proposed post labels before publication is implemented.

A post receives one label for each distinct source-quality category present in the eligible source assessments. A post linking to both low- and high-quality sources therefore receives both labels. Multiple sources in the same category produce one label. Do not average source scores or select an overall post rating. Unmatched and unresolved sources contribute no category.

Keep the agreed names: “Low quality news source”, “Medium quality news source”, and “High quality news source”. Each label describes a linked source category, not the accuracy of the post or the author's views. Retain the individual source assessments as evidence for the proposed labels.

## Quoted sources

Categories found in one quoted post also contribute labels to the submitted outer post, including when it has no direct article links. Do not inspect deeper quotes. Preserve “Source from quoted post” in the source evidence. If the quoted post is unavailable, retain proposals from known direct sources and show the existing unavailable-quote notice.

## Local behavior

Show the proposed label set in low, medium, high order above the individual source results. If no rated sources are found, show an explicit empty proposal. State that these are local proposals and nothing has been published to Bluesky. Publication, persistent decisions, and continuous ingestion remain future work.
